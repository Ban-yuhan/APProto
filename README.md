## 🕹️ 조작 방법
- **이동**: `W`, `A`, `S`, `D` 또는 `방향키` / **바닥 마우스 좌클릭 (Click-to-Move)**
- **시점 회전 및 줌**: **마우스 우클릭 드래그** (카메라 회전), **마우스 휠** (확대/축소)
- **발판 상호작용**: 원형 발판에 서 있으면 자동으로 택배 수거/적재 및 게이지가 진행됩니다.

## 📦 게임 루프 및 공정
1. **입고 공정**:
   - 실외 정차 구역으로 배송 트럭 후진 진입 (택배 10개 적재)
   - 트럭 앞 발판에서 택배 수거 ➔ 실내 입고 도크 상단 발판(택배 두기)에 적재
   - 입고 도크 하단 발판(택배 들기)에서 꺼내 다음 공정으로 이동
   - 트럭은 20초 대기 후 잔여분을 실은 채 회차 ➔ 쿨타임 뒤 새 트럭 도착
2. **분류 및 검수 공정**:
   - 송장 스캔 테이블 상단 발판에 택배 올리기 ➔ 우측 발판에서 3초 머물러 송장 스캔(대구/부산/서울 목적지 부여) ➔ 하단 발판에서 수거
   - 각 지역 분류대 상단 발판에 일치하는 목적지 택배 내려놓기
   - 분류대 우측 발판에서 3초간 검수 진행 ➔ 100% 완료 시 하단 영역으로 자동 이동
   - 분류대 하단 발판에서 검수 완료 택배 수거
3. **적재 및 출고 공정**:
   - 출고 도크에 검수 완료 택배 대기
   - 파렛트 포장대에서 택배 8개를 묶어 1개 파렛트로 압축 (출고 트럭 슬롯 1개만 차지, 8개로 정산)
   - 출고 트럭 상차 발판에서 트럭에 적재 (최대 10슬롯)
   - 5개 이상 적재 시 우측 '배송 출발' 버튼 활성화 ➔ 클릭 시 정산 및 출발
   - 최대 적재(10개) 출발 시 '알뜰적재' 보너스 발동 (평판 +10 및 보너스 머니 지급)

## 👥 알바(직원) 시스템
- 하단 [알바 관리] UI 오픈 (오픈 시 게임 일시정지)
- 고용 카드 3장 노출 (50원 소모 리롤 가능)
- **직종 5종**:
  - 하차 알바: 입고 도크 ➔ 스캔 테이블 운반
  - 스캔 알바: 스캔 테이블 상주 자동 스캔
  - 검수 알바: 분류대 상주 자동 검수 (최대 3명)
  - 운반 알바: 스캔 완료품 ➔ 분류대 & 검수 완료품 ➔ 출고 도크 운반 (최대 4명)
  - 상차 알바: 출고 도크 ➔ 배송 트럭 적재 (차량 출발 시 분류대로 자동 안전 반환 로직 내장)
- **단기 베테랑 알바**: 180초간 초고속(이속 2배, 작업 2배) 근무 후 퇴장
- **숙련도 시스템**: 신입(흰색) ➔ 일반(하늘색) ➔ 숙련(보라색) ➔ 베테랑(노란색)
